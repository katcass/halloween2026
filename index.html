Settings (for the phone, not the victim)

Remote buttons. A Bluetooth page turner or keyboard works. Right / Down / Page Down / Enter / Space = Answer. Left / Up / Page Up = Ring (or stop). Any other key, and the play/pause button on Bluetooth headphones, does the next step: ring, then answer, then hang up. Game controllers work too: A or D-pad right = Answer, B or D-pad left = Ring.
